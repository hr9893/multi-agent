# Project Overview

This repository contains a simple fitness tracking application built with Python. The core functionality includes calculating calories burned based on user input, providing exercise recommendations, and integrating with the **Groq** AI service for natural‑language responses.

## Key Components

- **`app/FitnessApp.py`** – Main application logic that handles user interaction, calorie calculations, and exercise suggestions.
- **`app/GroqService.py`** – Wrapper around the Groq API to generate AI‑driven feedback.
- **`main.py`** – Entry point that launches the command‑line interface.
- **`pyproject.toml`** – Build configuration and package metadata.
- **`requirments.txt`** – List of third‑party dependencies.

# Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your‑org/fitness‑app.git
   cd fitness‑app
   ```

2. **Create a virtual environment** (optional but recommended)
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # On Windows use `.venv\Scripts\activate`
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirments.txt
   ```

4. **Set up the Groq API key**
   The application expects an environment variable named `GROQ_API_KEY`. Add it to your shell or a `.env` file:
   ```bash
   export GROQ_API_KEY="your‑groq‑api‑key"
   ```

# Usage

Run the application from the project root:
```bash
python main.py
```

You will be prompted to enter your weight, height, age, gender, and the type of exercise you performed. The app will then:

- Calculate the estimated calories burned.
- Provide a brief description of the exercise.
- Generate an AI‑enhanced response using the Groq service.

Example interaction:
```
Enter your weight (kg): 70
Enter your height (cm): 175
Enter your age: 30
Enter your gender (male/female): male
Enter the exercise you performed: running
```
The program will output the calories burned and a friendly message.
